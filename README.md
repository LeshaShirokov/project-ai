# project-ai — дашборд учёта ИТ-проектов

Одностраничный дашборд на **чистом HTML, CSS и JavaScript** — без фреймворков, CDN и сборки.

**Демо:** https://leshashirokov.github.io/project-ai/

## Страницы

- **Аналитика** (`index.html`) — KPI и графики по всем проектам, ближайшие дедлайны (клик открывает проект на странице «Проекты»), переключатель темы, кнопка «Добавить проект».
- **Проекты** (`projects.html`) — список проектов: таблица/канбан, фильтры, поиск, сортировка, создание и редактирование, карточка с задачами, импорт/экспорт и управление данными.

Ссылки вида `projects.html#project=<id>` открывают карточку проекта, `projects.html#new` — форму нового проекта.

## Возможности

- KPI: всего проектов, в работе, завершено, просрочено, общий бюджет, потрачено (% бюджета), средний прогресс.
- Создание, редактирование и удаление проектов (с подтверждением): клиент, описание, статус, приоритет, стек, команда, даты, бюджет/расходы, прогресс, репозиторий, теги.
- Два представления: таблица и канбан (drag-and-drop + выбор статуса с клавиатуры).
- Фильтры по статусу, приоритету, технологии и тексту; сортировка по дедлайну, приоритету, прогрессу, бюджету, названию.
- SVG-графики: статусы (кольцевая), бюджет и расходы, технологический стек, ближайшие дедлайны.
- Чек-лист задач у проекта и режим «считать прогресс по задачам».
- Экспорт/импорт JSON, экспорт CSV (разделитель `;`, открывается в Excel) — на странице «Проекты».
- Светлая/тёмная тема, адаптивная вёрстка, доступность (клавиатура, ARIA, фокус в модальных окнах).
- Демо-данные при первом запуске, кнопки «Демо-данные» и «Очистить всё».

## Запуск

Откройте `index.html` в браузере или любой статический сервер:

```bash
python3 -m http.server 8000
```

## Хранение данных

Данные хранятся только в `localStorage` вашего браузера, общие для обеих страниц, и синхронизируются между вкладками. Для переноса или резервной копии используйте экспорт JSON.

## Структура

```
index.html         — страница «Аналитика»
projects.html      — страница «Проекты»
style.css
js/theme-init.js   — тема без мигания (обе страницы)
js/utils.js        — DOM-хелперы, даты, форматирование, CSV (обе)
js/store.js        — модель данных, валидация, хранение (обе)
js/ui.js           — модальные окна, уведомления, бейджи (обе)
js/shell.js        — тема, меню, синхронизация вкладок (обе)
js/charts.js       — SVG-графики (аналитика)
js/dashboard.js    — KPI и запуск страницы «Аналитика»
js/views.js        — таблица, канбан, карточка проекта (проекты)
js/projects.js     — фильтры, форма, импорт/экспорт (проекты)
```
