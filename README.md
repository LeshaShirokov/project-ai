# project-ai — дашборд учёта ИТ-проектов

Одностраничный дашборд на **чистом HTML, CSS и JavaScript** — без фреймворков, CDN и сборки.

**Демо:** https://leshashirokov.github.io/project-ai/

## Возможности

- KPI: всего проектов, в работе, завершено, просрочено, общий бюджет, потрачено (% бюджета), средний прогресс.
- Создание, редактирование и удаление проектов (с подтверждением): клиент, описание, статус, приоритет, стек, команда, даты, бюджет/расходы, прогресс, репозиторий, теги.
- Два представления: таблица и канбан (drag-and-drop + выбор статуса с клавиатуры).
- Фильтры по статусу, приоритету, технологии и тексту; сортировка по дедлайну, приоритету, прогрессу, бюджету, названию.
- SVG-графики: статусы (кольцевая), бюджет и расходы, технологический стек, ближайшие дедлайны.
- Чек-лист задач у проекта и режим «считать прогресс по задачам».
- Экспорт/импорт JSON, экспорт CSV (разделитель `;`, открывается в Excel).
- Светлая/тёмная тема, адаптивная вёрстка, доступность (клавиатура, ARIA, фокус в модальных окнах).
- Демо-данные при первом запуске, кнопки «Демо-данные» и «Очистить всё».

## Запуск

Откройте `index.html` в браузере или любой статический сервер:

```bash
python3 -m http.server 8000
```

## Хранение данных

Данные хранятся только в `localStorage` вашего браузера и синхронизируются между вкладками. Для переноса или резервной копии используйте экспорт JSON.

## Структура

```
index.html
style.css
js/theme-init.js  — тема без мигания
js/utils.js       — DOM-хелперы, даты, форматирование, CSV
js/store.js       — модель данных, валидация, хранение
js/charts.js      — SVG-графики
js/ui.js          — компоненты интерфейса и модальные окна
js/app.js         — состояние, фильтры, события
```
