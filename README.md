# project-ai — дашборд учёта ИТ-проектов

Многостраничный дашборд на **чистом HTML, CSS и JavaScript** — без фреймворков, CDN и сборки.

**Демо:** https://leshashirokov.github.io/project-ai/

## Страницы

- **Аналитика** (`index.html`) — KPI и графики по всем проектам, ближайшие дедлайны (клик открывает проект на странице «Проекты»), переключатель темы, кнопка «Добавить проект».
- **Проекты** (`projects.html`) — список проектов: таблица/канбан, фильтры, поиск, сортировка, создание и редактирование, выбор команды из контактов, карточка с задачами, импорт/экспорт и управление данными.
- **Контакты** (`contacts.html`) — люди: фото, ФИО, телефон, организация, почта, комментарии и отметка «Команда работников». Карточки/таблица, поиск, фильтры (все / только команда / внешние, по организации), сортировка, карточка контакта со списком его проектов.
- **Календарь** (`calendar.html`) — задачи по сроку закрытия и дедлайны/старты проектов в видах «День», «Неделя», «Месяц».

Ссылки:

- `projects.html#project=<id>` — карточка проекта, `projects.html#new` — форма нового проекта;
- `contacts.html#contact=<id>` — карточка контакта, `contacts.html#new` — форма нового контакта;
- `calendar.html#view=month|week|day&date=YYYY-MM-DD` — вид и дата календаря (например, `calendar.html#view=week&date=2026-10-28`).

## Возможности

- KPI: всего проектов, в работе, завершено, просрочено, общий бюджет, потрачено (% бюджета), средний прогресс, участников в команде.
- Создание, редактирование и удаление проектов (с подтверждением): клиент, описание, статус, приоритет, стек, команда, даты, бюджет/расходы, прогресс, репозиторий, теги.
- Два представления: таблица и канбан (drag-and-drop + выбор статуса с клавиатуры).
- Фильтры по статусу, приоритету, технологии и тексту; сортировка по дедлайну, приоритету, прогрессу, бюджету, названию.
- SVG-графики: статусы (кольцевая), бюджет и расходы, технологический стек, ближайшие дедлайны.
- Чек-лист задач у проекта и режим «считать прогресс по задачам». У задачи есть необязательный **срок закрытия** (поле даты в карточке проекта); рядом с задачей — «до ДД.ММ.ГГГГ», просроченные открытые задачи подсвечены красным.
- **Календарь**: виды «День», «Неделя», «Месяц» (неделя с понедельника), кнопки «‹ Сегодня ›», заголовок периода, выделение сегодняшнего дня.
  - Месяц — до 3 элементов в ячейке и «+N ещё» (открывает день), под сеткой — список выбранного дня; на телефоне вместо фишек цветные точки.
  - Неделя — 7 колонок со списком «весь день»; День — группы «Дедлайны проектов» и «Задачи», а для сегодняшнего дня ещё «Просрочено».
  - Цвет — проект; выполненные задачи зачёркнуты, просроченные — красные; дедлайны (⚑) и старты (▶) проектов — пунктирной рамкой.
  - Клик по элементу — карточка: отметка выполнения, смена срока, ссылка на проект. Отметить задачу выполненной можно прямо в календаре; кнопка «＋ Задача» добавляет задачу со сроком.
  - Фильтры: проект, статус (открытые/выполненные), показ дедлайнов и стартов проектов. Подсказка «N задач без срока» ведёт на «Проекты».
  - Клавиатура: стрелки — по дням, PageUp/PageDown — месяц, Home/End — начало/конец недели, Enter — открыть день.
- Контакты: фото (загружается с устройства, обрезается по квадрату и сжимается в браузере до 256 px JPEG; без фото — цветной аватар с инициалами), проверка телефона и почты, нормализация российских номеров к виду `+7 (900) 123-45-67`.
- **Команда проекта**: в форме проекта — список с поиском из контактов с отметкой «Команда работников». Участники показываются с аватарами в таблице, на канбане и в карточке проекта (со ссылками на контакты). Можно дописать участников, которых нет в контактах, текстом.
- Удаление контакта или снятие отметки «Команда работников» у участника проектов требует подтверждения и убирает его из команд.
- Экспорт/импорт JSON, экспорт CSV (разделитель `;`, открывается в Excel, защита от формул) — для проектов и отдельно для контактов (CSV контактов — без фото).
- Светлая/тёмная тема, адаптивная вёрстка, доступность (клавиатура, ARIA, фокус в модальных окнах).
- Демо-данные при первом запуске; кнопки «Демо-данные» и «Очистить» на страницах «Проекты» (только проекты) и «Контакты» (только контакты).

## Запуск

Откройте `index.html` в браузере или любой статический сервер:

```bash
python3 -m http.server 8000
```

## Хранение данных

Данные хранятся только в `localStorage` вашего браузера, общие для всех страниц, и синхронизируются между вкладками:

- `itpd.projects.v1` — проекты; команда — `teamIds` (ID контактов) и `team` (имена не из контактов);
- `itpd.contacts.v1` — контакты (фото — data URL, поэтому место ограничено квотой браузера, обычно ~5 МБ);
- `itpd.calendar` — последний вид, дата и фильтры календаря.

У задач проекта поле `due` (`YYYY-MM-DD` или пустая строка). Старые задачи без срока загружаются без изменений (срок пустой) и просто не видны в календаре; некорректная дата при загрузке/импорте превращается в пустую. Срок входит в экспорт/импорт JSON; в CSV проектов добавлены столбцы «Просроченных задач» и «Ближайший срок задачи».

Старые проекты, где команда была записана текстом, переносятся автоматически: имя, совпавшее (без учёта регистра, `ё`/`е` и лишних пробелов) ровно с одним контактом из команды работников, становится ссылкой на контакт; остальные имена сохраняются как текст.

Резервная копия: «Экспорт JSON» на странице «Проекты» сохраняет проекты **и** контакты (`{version: 1, projects, contacts}`); старые файлы без `contacts` импортируются как раньше и контакты не меняют. На странице «Контакты» экспорт/импорт JSON касается только контактов.

## Структура

```
index.html             — страница «Аналитика»
projects.html          — страница «Проекты»
contacts.html          — страница «Контакты»
calendar.html          — страница «Календарь»
style.css
js/theme-init.js       — тема без мигания (все страницы)
js/utils.js            — DOM-хелперы, даты, форматирование, CSV (все)
js/store.js            — проекты: модель, валидация, хранение (все)
js/contacts-store.js   — контакты: модель, валидация, хранение (все)
js/ui.js               — модальные окна, уведомления, бейджи, аватары (все)
js/team.js             — связь проектов и контактов, миграция команды (все)
js/shell.js            — тема, меню, синхронизация вкладок (все)
js/charts.js           — SVG-графики (аналитика)
js/dashboard.js        — KPI и запуск страницы «Аналитика»
js/views.js            — таблица, канбан, карточка проекта (проекты)
js/projects.js         — фильтры, форма, выбор команды, импорт/экспорт (проекты)
js/photo.js            — проверка и сжатие фото (контакты)
js/contacts.js         — список, фильтры, форма и карточка контакта (контакты)
js/cal-dates.js        — даты календаря: недели с понедельника, сетка месяца, заголовки (календарь)
js/calendar.js         — виды день/неделя/месяц, фильтры, карточка и форма задачи (календарь)
```
